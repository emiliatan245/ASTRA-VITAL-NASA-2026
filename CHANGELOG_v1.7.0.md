# ASTRA-VITAL v1.7.0 — Real Anatomy Integration

- Replaced the primary stylised procedural mannequin with the open-anatomy-3d male and female named GLB human anatomy models.
- Added actual skin, skeleton, muscle, organ, vessel and nerve layer visibility controls.
- Added real anatomy model loading status, mesh-aware body-system anchors and direct structure click mapping.
- Kept the bundled procedural 3D renderer as a labelled offline fallback.
- Added required CC BY 4.0 model attribution and provenance documentation.
- Documented internet requirement for first model load and the data privacy boundary: only anatomy model assets are fetched remotely; crew measurements are not uploaded.
- Uses a real, openly licensed anatomical GLB source rather than attempting to reproduce Kurzgesagt's proprietary illustrations or the previous AI-generated picture plates.
