# Install v1.4.2 welcome screen fix

1. Close the ASTRA-VITAL browser tab.
2. Back up your existing ASTRA_VITAL folder.
3. Extract `ASTRA_VITAL_v1.4.2_Update_Patch.zip`.
4. Open the `ASTRA_VITAL_v1.4.2_PATCH` folder.
5. Copy `index.html`, `body-view-ui.js`, and `astra-blue-final.css` into your existing ASTRA_VITAL folder.
6. Choose Replace when Windows asks.
7. Reopen `index.html` and press Ctrl+Shift+R.

The welcome screen should now appear. The new **WELCOME** button in the flight-deck top bar can reopen it later. Your saved records are stored in browser localStorage and are not changed by this update.
