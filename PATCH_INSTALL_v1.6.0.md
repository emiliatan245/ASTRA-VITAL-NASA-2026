# ASTRA-VITAL v1.6.0 update patch installation

1. Close the ASTRA-VITAL browser tab.
2. Back up the current project folder and export any local CSV records as a precaution.
3. Extract `ASTRA_VITAL_v1.6.0_Update_Patch.zip`.
4. Copy the patch contents into the existing project root (the folder containing `index.html`).
5. Replace `index.html`, `body-view-ui.js`, and `mission-features.js` when prompted.
6. Add `astra-3d-anatomy.js` and `astra-3d-viewer.css` to that same project root.
7. Reopen `index.html` in Chrome or Edge; press Ctrl + Shift + R.
8. Open Anatomy explorer, choose Male or Female, choose an anatomy mode, then drag to rotate and scroll to zoom.

No new image or remote library is required. Existing assets and browser-local check-in records are not intentionally cleared by this patch. Keep your backup until the new build is confirmed.
