# ASTRA-VITAL v1.5.0 — Anatomy Station

- Reworked the anatomy explorer to match the wide two-column workstation layout.
- Added compact male/female reference selector and six anatomical view tabs.
- Added the All Systems comparison plate (skeleton, internal organs/circulation, muscular system).
- Added Auto-rotate, Microgravity and Reset view controls. These are illustrative visual modes, not physical simulations or a rotatable anatomical mesh.
- Rebuilt image sizing and pointer alignment around a shared responsive image wrapper.
- Kept the educational, non-diagnostic boundaries and existing health-assessment workflow.
