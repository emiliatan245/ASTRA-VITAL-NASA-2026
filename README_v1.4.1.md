# ASTRA-VITAL v1.4.1

This release fixes the anatomy display where markers could appear detached from the illustration and the figure could look too small within the blue-black stage.

## Anatomy views
- Normal body reference (Male / Female selection)
- Nervous system
- Organs & circulation
- Skeleton
- Muscular system

Six numbered body-system pointers are positioned relative to the visible illustration. Their labels appear on hover, keyboard focus, or selection. Selecting a pointer continues to update the system information panel.

## Run
Extract the complete ZIP, keep all assets alongside `index.html`, then open `index.html` in Chrome or Edge.

## Install patch
For an existing v1.4.0 folder, follow `PATCH_INSTALL_v1.4.1.md`. Do not replace the assets folder; existing assets are retained.

## Scope and safety
This is an educational prototype. Art is static AI-generated educational illustration, not a rotatable 3D mesh, diagnostic image, validated anatomy atlas, or clinical instrument. Pointer locations are for navigation only.
