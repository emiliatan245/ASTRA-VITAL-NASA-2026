# Install ASTRA-VITAL v1.4.1 anatomy display fix

1. Close the ASTRA-VITAL browser tab.
2. Make a copy of your existing project folder as a backup.
3. Extract `ASTRA_VITAL_v1.4.1_Update_Patch.zip`.
4. Copy `index.html`, `body-view-ui.js`, and `anatomy-layout-fix.css` into your existing v1.4.0 project folder.
5. Replace `index.html` and `body-view-ui.js` when Windows asks. Add `anatomy-layout-fix.css` as a new file.
6. Keep the existing `assets` folder and all other JavaScript/CSS files in place.
7. Reopen `index.html` and press Ctrl+Shift+R.

No local-storage keys or saved observations are changed by this patch. Keep a CSV export as a backup before updating.

For a clean install, use `ASTRA_VITAL_v1.4.1_Complete_Project.zip` and open its `ASTRA_VITAL_v1.4.1/index.html` file.
