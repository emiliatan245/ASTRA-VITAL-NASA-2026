# ASTRA-VITAL v1.7.1 named-pointer update

1. Back up the existing ASTRA-VITAL project folder.
2. Extract this update ZIP.
3. Copy the included files into the same folder that contains your current `index.html`.
4. Replace matching files when Windows prompts.
5. Keep the existing `assets` folder and all model/data files.
6. Open `index.html` in Chrome or Edge and press **Ctrl + Shift + R**.

This update changes only anatomy pointer visuals, labels, related helper text, and the version marker. It does not intentionally clear browser localStorage or modify observations, synthetic sensor data, or the model.
