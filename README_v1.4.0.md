# ASTRA-VITAL v1.4.0 — release notes

The v1.4.0 release responds to the participant's request for a more professional anatomical explorer and a unified black/blue interface.

## Main updates
- Separate full-body Male and Female reference buttons before anatomy exploration.
- Separate normal-body artwork for each selected reference.
- Five anatomy views: Normal body, Nervous system, Organs & circulation, Skeleton, and Muscular system.
- Existing detailed skeleton, muscular, and internal/circulation plates are used in their matching modes.
- Nervous-system SVG references respond to the Male/Female selection.
- A visible profile gate prevents the simplified silhouette placeholder from appearing before a reference is chosen.
- Numbered pointers open the related body-system information panel.
- Unified blue/black glass styling across the welcome screen, flight deck, forms, panels, cards, and anatomy explorer.
- Welcome scroll parallax moves the mission visual with the page; the launch button triggers a rocket takeoff transition.
- Full-card anchor behavior remains enabled for the NASA OSDR study and research resource cards.

## Boundaries
The body images are AI-assisted educational illustrations, not validated anatomy diagrams, scans, or medical images. The selected body reference is a visual preference only. It does not change the synthetic model, thresholds, measurements, or health interpretation. The AI model remains trained on synthetic examples and must not be used for real health decisions.
