# ASTRA-VITAL v1.4.0 update patch

1. Back up the existing ASTRA_VITAL folder and export local records to CSV.
2. Extract `ASTRA_VITAL_v1.4.0_Update_Patch.zip`.
3. Copy the patch files into the existing project folder.
4. Replace files when Windows asks; merge the included `assets` folder.
5. Reopen `index.html` and press Ctrl + Shift + R.

The patch updates `index.html`, the anatomy/welcome interaction script, the final blue theme, the logo and the two new normal-body reference images. It keeps the existing assessment/model scripts and data files in place.

If your folder is older than v1.3.0, use the complete project ZIP instead.
