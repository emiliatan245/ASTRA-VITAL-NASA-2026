# Install ASTRA-VITAL v1.5.0 update

1. Back up the current project folder and export any local CSV records.
2. Extract the patch ZIP.
3. Copy `index.html`, `body-view-ui.js`, and `anatomy-station-v1.5.css` into the existing project folder.
4. Copy `assets/astra-anatomy-atlas.webp` into the existing `assets` folder.
5. Replace files when asked, keeping all other assets and scripts.
6. Reopen `index.html` and press Ctrl+Shift+R.

The controls provide visual illustration motion only. The images are static educational artwork with clickable overlays, not a true rotatable 3D anatomical mesh or diagnostic imagery.
